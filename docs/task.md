# Техническое задание для команды

## Что вы создаёте

Учебный магазин на выбранную тему: книги, настольные игры, космическая еда или что-то своё. Пользователь открывает сайт, выбирает товары и собирает корзину. Заказ и оплата не обязательны.

Обязательная версия работает в браузере на HTML, CSS и JavaScript. Можно использовать инструмент сборки, если команда умеет получать готовую статическую сборку. Go, Java, C# или Python могут обслуживать файлы локально или использоваться для дополнительного backend. Статический хостинг серверный код этих языков не запускает.

## Обязательный минимум

Достаточно одной страницы и трёх товаров. Если работают четыре пункта ниже, основная часть задания выполнена. Дополнительные функции можно вообще не делать.

| Функция | Как проверяем |
|---|---|
| Каталог | Не менее 3 товаров. У каждого есть название, цена в рублях и кнопка «Добавить» |
| Добавление в корзину | Выбранный товар появляется в списке корзины |
| Удаление из корзины | Товар можно убрать из корзины |
| Общая сумма | Сумма соответствует товарам в корзине и меняется после добавления и удаления. В пустой корзине — 0 ₽ |

Можно использовать целые цены без копеек. Повторное добавление разрешено сделать отдельной строкой или просто не добавлять товар второй раз — выберите удобный вариант. Счётчик количества не обязателен.

**Пример проверки:** добавьте товар за 100 ₽ и товар за 200 ₽ — итог 300 ₽. Удалите первый — итог 200 ₽. Удалите второй — корзина пуста, итог 0 ₽.

Достаточно работы в браузере на ноутбуке. Дизайн может быть простым, но названия, цены и кнопки должны быть понятны. Картинки, категории и мобильная версия не обязательны. После перезагрузки корзина может очищаться.

## Дополнительные задачи — по желанию

Выберите любую интересную задачу, когда обязательный минимум уже работает. Не нужно выполнять весь список.

| Задача | Что можно сделать и показать |
|---|---|
| Изображения и оформление | Добавить картинки товаров и аккуратно оформить страницу |
| Количество товаров | Кнопки «+» и «−», пересчёт суммы; количество не бывает отрицательным |
| Сохранение корзины | После перезагрузки выбранные товары остаются в том же браузере |
| Категории и фильтр | Показывать товары выбранной категории и возвращаться ко всем товарам |
| Поиск или сортировка | Найти товар по названию или упорядочить по цене |
| Промокод | Один код даёт скидку 10%; неверный код объясняется, повторное применение не увеличивает скидку |
| Удобство интерфейса | Работа на телефоне или управление с клавиатуры |
| Другие функции | Избранное, страница товара, ограничение по остаткам |
| Автоматические тесты | Проверки расчёта суммы или действий с корзиной |
| Backend | API каталога на Go, Java, C# или Python |
| Деплой | Публичная ссылка, обновление, откат, автодеплой или свой домен |

Если выбрали сохранение, используйте для `localStorage` ключ с номером команды, например `team07:cart:v1`. Если выбрали промокод, проверьте: 300 ₽ со скидкой 10% дают 270 ₽, повторное применение оставляет 270 ₽.

Backend, база данных, Docker, регистрация покупателей и платёжная интеграция не обязательны. Если добавляете API, отдельно решите вопрос его размещения: загрузка HTML на статический хостинг его не публикует.

## Что передать

Исходный код, README с запуском, ZIP готового сайта и краткий список реализованных функций. Публичная ссылка добавляется при выполненном деплое. Подробности — в [чек-листе](submission.md).

Не копируйте секреты и `.env` в публичные файлы. Любое значение в JavaScript браузера доступно посетителю. Используйте вымышленные товары и изображения, которые разрешено публиковать.
