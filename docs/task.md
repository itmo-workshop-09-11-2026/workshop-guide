# Техническое задание для команды

## Что вы создаёте

Учебный магазин на выбранную тему: книги, настольные игры, космическая еда или что-то своё. Пользователь открывает сайт, выбирает товары и собирает корзину. Заказ и оплата не обязательны.

Обязательная версия работает в браузере на HTML, CSS и JavaScript. Можно использовать инструмент сборки, если команда умеет получать готовую статическую сборку. Go, Java или C# могут обслуживать файлы локально или использоваться для дополнительного backend. Статический хостинг серверный код этих языков не запускает.

## Обязательные функции

| Функция | Как проверяем |
|---|---|
| Каталог | Не менее 6 товаров из 2 категорий. У каждого есть стабильный ID, название, цена и изображение либо понятная заглушка |
| Добавление в корзину | Повторное добавление увеличивает количество, а не создаёт непонятные дубликаты |
| Управление корзиной | Количество можно изменить; товар можно удалить; отрицательные и дробные количества не принимаются |
| Итог | Общая сумма пересчитывается при каждом изменении, пустая корзина показывает 0 |
| Сохранение | После перезагрузки страницы корзина восстанавливается в том же браузере |
| Фильтр | Можно выбрать категорию и вернуться ко всем товарам; пустой результат объяснён |
| Промокод | Есть один код со скидкой 10%; неизвестный код показывает ошибку; повторное применение не накапливает скидку |
| Понятный интерфейс | Кнопки подписаны, цена указана с валютой, на узком экране основные действия доступны |

Цены храните в целых копейках, итог округляйте до копеек. Пример: два товара по 1 000 ₽ и один за 500 ₽ дают 2 500 ₽; скидка 10% — 2 250 ₽. После удаления товара за 500 ₽ итог со скидкой — 1 800 ₽.

Корзина сохраняется на этом устройстве и в этом браузере. Общая корзина между устройствами не требуется. Для `localStorage` используйте ключ с номером команды, например `team07:cart:v1`. Повреждённые сохранённые данные не должны ломать страницу: можно сбросить корзину с понятным уведомлением.

## Дополнительные задачи

Выберите то, что успеете проверить:

- Поиск по названию, сортировка по цене.
- Избранное или страница товара.
- Ограничение по остаткам и сообщение «нет в наличии».
- Доступность с клавиатуры, подписи для полей и изображений.
- Автоматические тесты расчётов и пользовательских сценариев.
- Backend на Go, Java или C# с API каталога; браузерная версия при этом остаётся демонстрируемой.
- Самостоятельный деплой, повторное обновление, откат, автодеплой, собственный домен.

Backend, база данных, Docker, регистрация покупателей и платёжная интеграция не обязательны. Если добавляете API, отдельно решите вопрос его размещения: загрузка HTML на статический хостинг его не публикует.

## Что передать

Исходный код, README с запуском, ZIP готового сайта и краткий список реализованных функций. Публичная ссылка добавляется при выполненном деплое. Подробности — в [чек-листе](submission.md).

Не копируйте секреты и `.env` в публичные файлы. Любое значение в JavaScript браузера доступно посетителю. Используйте вымышленные товары и изображения, которые разрешено публиковать.
