# Сдача и достижения

## Основная сдача

- [ ] Репозиторий доступен ментору, в README есть команды запуска и требования к окружению.
- [ ] Указаны команда, участники и распределение работы; достаточно имён или GitHub-ников, без телефонов и почты.
- [ ] Есть минимум 3 товара с названием, ценой и кнопкой добавления.
- [ ] Товары добавляются в корзину и удаляются из неё.
- [ ] Общая сумма пересчитывается; в пустой корзине — 0 ₽. Проверен пример из ТЗ.
- [ ] Сайт работает из распакованного ZIP; стили, скрипты и картинки, если они используются, загружаются.
- [ ] В архиве `index.html` лежит в корне; секретов и зависимостей разработки нет.
- [ ] Записаны известные проблемы и то, что не успели.

Создайте [issue по форме](https://github.com/itmo-workshop-09-11-2026/workshop-guide/issues/new?template=submission.md): одна issue на команду и дату, например «Сдача: Мур — 9 ноября». Прикрепите ZIP к тексту issue и обновляйте эту же issue при изменениях. Если GitHub отклоняет размер архива, передайте его ментору и укажите это в issue. Если аккаунта GitHub нет, ментор может оформить сдачу за команду. Публичный деплой не заменяет исходники.

## Дополнительные функции

Фильтры, промокоды, изменение количества, сохранение корзины, картинки и мобильная версия — по желанию. Их отсутствие не мешает сдать основную часть. Если что-то добавили, укажите это в отчёте и покажите, как проверяли.

## Отдельные достижения за деплой

Это качественные отметки, а не утверждённая балльная система.

| Достижение | Что показать ментору |
|---|---|
| «В интернете» | Рабочая публичная HTTPS-ссылка без входа |
| «Обновляем» | Видимое изменение сайта по тому же адресу после новой публикации |
| «Можем вернуть» | Откат к прошлой работающей сборке |
| «Само публикуется» | Изменение в Git запускает успешный деплой |
| «Свой адрес» | Собственный домен с рабочим HTTPS |

Платный сервис не даёт преимущества. За локально работающий магазин без деплоя можно сдать всю обязательную часть. Помощь ментора разрешена; команда должна объяснить и повторить показанные действия.

## Шаблон отчёта

Скопируйте в README проекта или issue по форме этого репозитория:

```text
Команда и дата участия:
Участники и роли:
Репозиторий:
Commit ID финальной версии:
Команда локального запуска:
Где находится ZIP готового сайта:
Что реализовали:
Что проверили:
Известные проблемы:
Основной публичный URL (если есть):
URL конкретного deployment (если есть):
Достижения по деплою и как их проверили:
```

Не добавляйте в отчёт токены, коды восстановления или пароли. Commit ID можно получить командой `git rev-parse HEAD` либо скопировать со страницы коммита GitHub.

## Демо на две минуты

Покажите каталог, добавление двух товаров, общую сумму и удаление товаров до пустой корзины. Если сделали дополнительные функции, покажите одну из них. Если выполнен деплой, откройте публичную ссылку и расскажите, как её обновлять. Завершите одной проблемой, которую команда нашла и исправила вместе с агентом.
