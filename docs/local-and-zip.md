# Запустить → упаковать

## Структура без сборки

```text
my-shop/
  README.md
  site/
    index.html
    styles.css
    app.js
    assets/
```

Папка `site` содержит только публичные файлы. Ссылки на ресурсы делайте относительными: `./styles.css`, `./app.js`, `./assets/product.jpg`. Это помогает при размещении магазина в подпапке GitHub Pages.

## Локальный запуск без Docker

Если используете языковой шаблон, сначала выполните команды из его README. Следующий способ подходит для любой готовой статики при установленном Python 3.

Откройте терминал в `my-shop` (в Windows можно открыть PowerShell через меню папки).

Windows:

```powershell
py -3 -m http.server 8000 --bind 127.0.0.1 --directory site
```

macOS / Linux:

```bash
python3 -m http.server 8000 --bind 127.0.0.1 --directory site
```

Откройте `http://localhost:8000`. Терминал должен оставаться открытым. Для остановки нажмите Ctrl+C. Если порт занят, замените 8000 на 8001 и измените адрес в браузере.

Если Python не установлен, используйте сервер из шаблона либо расширение Live Server в VS Code. Открытие `index.html` двойным щелчком годится только для простого предварительного просмотра: загрузка JSON и модули JavaScript через `file://` могут не работать.

Для проекта со сборкой выполните команды из его README. Например, результатом может быть папка `dist`. Запускайте HTTP-сервер над ней, заменив `site` на `dist`. На публикацию отправляйте результат сборки, а не исходники.

## Создание ZIP

В корне архива должен быть `index.html`, а не дополнительная папка `site` или `dist`.

Windows, из папки `my-shop`:

```powershell
Compress-Archive -Path .\site\* -DestinationPath .\shop.zip -Force
```

macOS / Linux, из папки `my-shop` (понадобится утилита `zip`):

```bash
(cd site && zip -r ../shop-new.zip . -x '*.DS_Store')
```

Для повторной упаковки удалите предыдущий `shop-new.zip` или возьмите новое имя: `zip` обновляет существующий архив и может сохранить ранее удалённые файлы.

Через проводник: откройте `site`, выделите её содержимое и создайте ZIP. В macOS команда называется «Сжать», в Windows — «Сжать в ZIP-файл» либо «Отправить → Сжатая ZIP-папка».

Распакуйте архив в новую папку и повторите запуск уже из неё. Проверьте каталог, изображения и корзину. Не включайте `.git`, `.env`, `node_modules`, SDK и серверные исходники. Ориентир для сдачи: до 50 МБ распакованного сайта; ограничения конкретного хостинга могут быть строже.
