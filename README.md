# Магазин за три часа: воркшоп с AI-агентами

Ваша команда из пяти человек создаёт учебный интернет-магазин. AI-агент помогает писать код, а вы выбираете задачи, проверяете результат и объясняете, как всё работает.

**Главная цель — работающий магазин. Самостоятельный деплой — отдельное достижение, за которое команда получает дополнительный респект.** Общего сервера публикации и командных кодов доступа нет. Для публикации достаточно аккаунта одного участника на выбранной площадке; всем пятерым регистрироваться там не нужно.

## С чего начать

1. Прочитайте [ТЗ](docs/task.md) и распределите роли.
2. Возьмите стартовый шаблон у ведущего через **Use this template → Create a new repository**. Если шаблон ещё недоступен, начните с папки `site/` и файлов `index.html`, `styles.css`, `app.js`.
3. Запустите сайт по [инструкции](docs/local-and-zip.md).
4. Сделайте минимум: 3 товара, добавление и удаление из корзины, общую сумму. Всё остальное — по желанию.
5. Проверьте магазин по [чек-листу сдачи](docs/submission.md).
6. Если осталось время, [опубликуйте сайт](docs/deploy.md) и покажите обновление по той же ссылке.

Этот репозиторий содержит задание и инструкции. Выберите один стартовый шаблон:

| Язык | Репозиторий | Что установить |
|---|---|---|
| Go | [shop-go](https://github.com/itmo-workshop-09-11-2026/shop-go) | Go 1.24+ |
| Java | [shop-java](https://github.com/itmo-workshop-09-11-2026/shop-java) | JDK 21+ |
| C# | [shop-csharp](https://github.com/itmo-workshop-09-11-2026/shop-csharp) | .NET SDK 10 |
| Python | [shop-python](https://github.com/itmo-workshop-09-11-2026/shop-python) | Python 3.12+ |

В каждом шаблоне есть запуск без Docker, команда упаковки ZIP и необязательная публикация через GitHub Actions. Готовой реализации магазина нет.

Сдача — [issue по форме](https://github.com/itmo-workshop-09-11-2026/workshop-guide/issues/new?template=submission.md) в этом репозитории: одна issue на команду и дату. Прикрепите ZIP, ссылку на исходники и публичный сайт, если опубликовали.

## Дополнительные задачи

Основной минимум остаётся простым. По желанию выбирайте задачи интерфейса, backend, качества и деплоя из [расширенного ТЗ](docs/task.md). Backend можно демонстрировать локально; платный сервер не нужен.

## Пример для просмотра

[Демо-магазин на GitHub Pages](https://itmo-workshop-09-11-2026.github.io/demo-shop/) — три товара, корзина и общая сумма. Ссылка заработает после первой публикации демо организатором.

## Как распределить три часа

| Время | Результат |
|---|---|
| 0–15 минут | Команда, тема магазина, репозиторий, первый локальный запуск |
| 15–65 минут | Каталог и работающая корзина |
| 65–105 минут | Проверка обязательного минимума и исправления |
| 105–135 минут | Доработка основной части или дополнительные функции по желанию |
| 135–160 минут | Самостоятельный деплой, если базовая часть готова |
| 160–180 минут | Финальная проверка, сдача и короткое демо |

Роли: координатор, каталог и интерфейс, корзина и расчёты, тестирование, интеграция и деплой. Это зоны ответственности, а не запрет помогать друг другу. Не редактируйте один файл одновременно без договорённости.
